# صفحة أجواء لتنظيف الكنب والمجالس

صفحة هبوط عربية خفيفة وسريعة، جاهزة للرفع مباشرة على GitHub Pages أو أي استضافة ملفات ثابتة.

## النشر على GitHub Pages

1. ارفع ملفات المجلد إلى المستودع، بحيث يكون ملف `index.html` في الصفحة الرئيسية للمستودع.
2. من إعدادات المستودع افتح **Pages**.
3. اختر النشر من الفرع `main` ومن المجلد الجذر `/root`، ثم احفظ.
